# کارگاه — برنامه‌ریزی شخصی با قیمت زنده

اپ سبک فارسی/RTL برای کارهای روزمره، پروژه‌ها، حساب‌وکتاب و **رصد خودکار قیمت کالا**.
بدون build؛ فقط HTML/CSS/JS. دو حالت اجرا دارد:

| حالت | داده‌ها | قیمت‌ها |
| --- | --- | --- |
| **آنلاین (GitHub Pages + Supabase)** | حساب کاربری، هم‌زمان روی همهٔ دستگاه‌ها | با Edge Function از ترب خوانده می‌شود |
| **محلی (اختیاری)** | فقط همین مرورگر | `server.py` روی همین کامپیوتر |

## ساختار

```
index.html, styles.css, app.js   خود اپ
config.js                        آدرس/کلید عمومی Supabase (حالت آنلاین)
icon.svg                         فاوآیکون
supabase/functions/kargah-price/ تابع لبه: جستجو، افزودن، بررسی و تازه‌سازی قیمت
server.py (+ start.bat)          سرور محلی اختیاری برای حالت بدون حساب
```

## اجرا

### آنلاین
آدرس نهایی: **https://armvnhs.ir/kargah/**

1. ریپو: `github.com/armvnhs/kargah` — Pages از شاخهٔ `main` و پوشهٔ `/` منتشر می‌شود.
2. دامنهٔ `armvnhs.ir` روی ریپوی کاربری (`armvnhs.github.io`) تنظیم است، پس این پروژه خودکار زیر
   `armvnhs.ir/kargah/` سرو می‌شود.
3. در Supabase → Authentication → URL Configuration همین آدرس Site URL است.
4. صفحه را باز کن، «ساخت حساب» را بزن و وارد شو. از این به بعد هر دستگاهی با همان حساب همان داده‌ها را می‌بیند.

### محلی (بدون حساب)
```bash
python server.py      # یا دوبار کلیک روی start.bat
```
سپس `http://127.0.0.1:8765`. در صفحهٔ ورود «بدون حساب ادامه بده» را بزن.

## بک‌اند Supabase

- جدول `public.kargah_state` — یک ردیف برای هر کاربر (`user_id`, `data jsonb`, `updated_at`) با RLS:
  هر کس فقط ردیف خودش را می‌خواند/می‌نویسد.
- تابع `kargah-price` (Deno، بدون وابستگی) با دستورهای `state | search | add | check | refresh`.
  قیمت‌ها از ترب و صفحهٔ فروشگاه‌ها خوانده و روزی یک نقطه در تاریخچه ثبت می‌شود.
- تازه‌سازی قیمت وقتی انجام می‌شود که اپ باز شود و بیش از ۶ ساعت از آخرین بررسی گذشته باشد
  (به‌علاوهٔ دکمهٔ «بررسی همه» و بررسی خودکار هر ۱۵ دقیقه تا وقتی اپ باز است).

### بازنشر تابع
```bash
# با Supabase CLI
supabase functions deploy kargah-price --project-ref youkoumtyartbmyhxgcn
```

## نکته‌ها

- کلید داخل `config.js` همان کلید **عمومی** anon است و برای مرورگر است؛ امنیت با RLS و JWT کاربر تأمین می‌شود.
  کلید service_role هرگز در این پروژه نیست.
- برای صفحهٔ فروشگاهی، اگر خود سایت داده‌اش را اشتباه گذاشته باشد همان عدد خوانده می‌شود؛
  دقیق‌ترین منبع، لینک محصول از **ترب** است.
- داده‌های حالت محلی در `data/prices.json` است و در git نادیده گرفته می‌شود.
